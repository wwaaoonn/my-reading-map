# data ディレクトリ

## sample_reading_log.csv

動作確認用のサンプル（20冊）です。著作権の問題が起きないようパブリックドメインの
作品を選び、説明文は本リポジトリの著者が書き下ろしています。

```bash
python main.py data/sample_reading_log.csv
```

## 読書ログCSVの仕様

必要な列は2つだけです。

| 列 | 必須 | 使われ方 |
| --- | --- | --- |
| `タイトル` | ○ | 図のラベルに使う |
| `説明文` | ○ | **この文章だけがベクトル化の対象**。本の裏表紙などに書かれた内容紹介を想定 |
| `ID` `著者` `出版社` `作成日` | | あれば出力CSVにそのまま引き継ぐ |

列が足りない場合、3冊未満の場合、内容の異なる説明文が2件未満の場合はエラーで止まります。
説明文が空の行は、件数を表示して処理を続けます（その本はベクトルが意味を持たないので、
地図上の位置も参考になりません）。

## 自分の読書記録を入れる場所

このリポジトリには著者自身の読書記録を置いていません。手元で使う場合は、
`.gitignore` 済みのディレクトリ（`_local/` など）に置くか、リポジトリの外に置いて
パスを渡してください。

```bash
python main.py ~/Documents/読書記録.csv
```

出版社の内容紹介をそのまま説明文に使っている場合、そのCSVを公開リポジトリに
置くのは避けたほうが安全です。パイプラインは説明文を除いた
`clustered_books_public_<時刻>.csv` も同時に出力するので、結果を共有したいときは
そちらを使ってください。
